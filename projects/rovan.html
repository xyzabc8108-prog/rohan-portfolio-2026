CASE STUDY / INDEX01 / OVERVIEW02 / CURRENT WORK03 / EVIDENCE & LIMITS04 / NEXT STEPS

01 / WHAT IT IS

THE CONCEPT.

The goal is a practical personal voice assistant that can be experimented with locally, without claiming a fully autonomous or publicly usable product.

HONEST CREDIT The project idea and direction are mine. AI tools generated most of the implementation. My own testing has been limited and the project status is reported accordingly.

02 / CURRENT WORK

WHAT EXISTS.

  • A local Ollama setup and a small language model for on-device responses.
  • Offline speech recognition experiments with Whisper and text-to-speech output.
  • Wake-phrase tests and a conversational prototype run in a controlled Windows environment.

03 / EVIDENCE & LIMITATIONS

WHAT'S KNOWN.

  • The local prototype has been tested for wake phrases, microphone capture and voice output in the development setup.
  • Those checks are narrower than full, repeated reliability testing across environments.
  • The local assistant is separate from any owner-only cloud command-center prototype and is not publicly hosted.
VISUAL EVIDENCE The illustration on this page is original portfolio artwork, not a screenshot. A verified, permission-cleared product screenshot or recording can be added later.

04 / WHAT COMES NEXT

STILL TO DO.

Proposed next steps — not completed deliverables

  • Review false wake activations and latency across real environments.
  • Refine safe confirmation and permission flows before enabling meaningful device actions.
  • Add repeatable offline regression tests and clearer local setup documentation.
