01 / WHAT IT IS

THE CONCEPT.

The project is an experimental browser-first workflow for arranging vehicle photos, selecting styles and producing short social-video exports. AI tools have been used extensively for implementation. This is not a completed professional editor.

HONEST CREDIT The project idea and direction are mine. AI tools generated most of the implementation. My own testing has been limited and the project status is reported accordingly.

02 / CURRENT WORK

WHAT EXISTS.

  • A password-gated private web app deployed on Render and backed by a private GitHub repository.
  • Photo-based vertical video editing options and MP4 export, including motion presets and optional local audio upload.
  • A media workspace for uploading/selecting photos; some generated or imported media uses temporary storage.

03 / EVIDENCE & LIMITATIONS

WHAT'S KNOWN.

  • The source repository and Render service exist under the connected account; the live application is owner-only.
  • The implementation is photo-based rather than a full multitrack drag-and-drop video editor.
  • Storage on the hosting plan can be ephemeral, and third-party stock/media rights require verification. No claim of public access or automatic Instagram posting.
VISUAL EVIDENCE The illustration on this page is original portfolio artwork, not a screenshot. A verified, permission-cleared product screenshot or recording can be added later.

04 / WHAT COMES NEXT

STILL TO DO.

Proposed next steps — not completed deliverables

  • Keep improving the photo timeline and export reliability.
  • Validate licensing and media attribution before broader public use.
  • If released publicly, add appropriate access control, durable storage and thorough end-to-end testing.
