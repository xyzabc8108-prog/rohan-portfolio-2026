DESIGN
- Warm ivory, charcoal and muted bronze; serif/editorial typography and original project illustrations.
- Approximately five-second cinematic opening transformation (typography and paper shutter, not glow).
- Intro is skippable with a button or Escape. It normally plays once per browser session, with a footer Replay option.
- Reduced-motion accessibility setting skips the intro and animations.
- Responsive mobile navigation, clear focus indicators and a standalone stylesheet.
- Five matching classic case-study pages.
- No paid APIs, extra build step, tracking scripts, image libraries or external image dependencies.
- A visible link to the existing Digital Lab website; the Digital Lab homepage is not edited.
